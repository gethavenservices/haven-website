# 🏠 Haven — India’s Trusted Hyperlocal Skilled-Service Ecosystem

**Haven** is a tech-enabled ecosystem designed to bridge the gap between households and verified skilled professionals. From emergency repairs to subscription-based maintenance, we are modernizing the home service industry in India.

[Live Demo](https://gethaven.in) | [Join Waitlist](https://gethaven.in)

---

## 🚀 Key Features
*   **Hyperlocal Quick-Response:** Emergency support for plumbing, electrical, and AC issues in under 60 minutes.
*   **Subscription Ecosystem:** Proactive weekly, monthly, and annual maintenance plans for a worry-free home.
*   **Verified Workforce:** Rigorous 5-step background checks and skill certification for all professionals.
*   **Brand Partnerships:** Future integrations with appliance giants like Samsung, LG, and Whirlpool.

## 🛠️ The Tech Stack
Built with a modern, high-performance stack for a premium user experience:
- **Framework:** [React.js](https://reactjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Dark Mode UI)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## 📈 Vision & Workforce Empowerment
Haven isn't just a service app; it's a social mission. We are partnering with ITIs and Vocational Centers to:
- Upskill local talent.
- Provide career development for the blue-collar workforce.
- Reduce overseas service dependency.

## 📦 Local Setup
1. Clone the repo: `git clone https://github.com/your-username/haven-website.git`
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
